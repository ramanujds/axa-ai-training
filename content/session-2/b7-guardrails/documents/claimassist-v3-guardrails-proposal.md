# ClaimAssist v3: Guardrails Section of the Vendor Proposal

**Fictional - for training only. Vendor and product are made up.**

**Vendor:** Nimbus AI Solutions Ltd
**Product:** ClaimAssist v3 (agent that drafts and sends settlement letters)

## Section 6: Safety and control

ClaimAssist v3 is built with layered protection.

| Ref | Layer | Statement in the proposal |
| --- | --- | --- |
| G1 | Access controls | Handlers only see claims assigned to them. |
| G2 | Input filters | Hidden instructions in uploaded documents are blocked. |
| G3 | Data-loss prevention | Sensitive data is blocked from leaving. |
| G4 | Output filters | Harmful or wrong content is filtered before it is shown. |
| G5 | Human approval | Letters are approved by a handler before they are sent. |
| G6 | Monitoring and audit trail | All activity is logged and monitored. |
| G7 | Escalation | Incidents are escalated immediately, and the system can be stopped at any time. |
